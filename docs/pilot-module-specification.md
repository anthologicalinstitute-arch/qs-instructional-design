Quantum Sims™ — Pilot Learning Module Specification

Status: Draft — awaiting review
Version: 0.1
Repository: qs-instructional-design

1. Purpose

Pilot the learning-objective and assessment framework using one introductory module. Test whether learners can explain a model, interpret results, apply a method, and recognize uncertainty and limitations.

2. Intended learner

A beginner or early-stage researcher learning how to evaluate a documented computational model.

Prerequisites: Basic quantitative reasoning and the ability to follow written instructions.

3. Learning outcomes

By the end of the module, the learner should be able to:

1. Identify a model's purpose, inputs, outputs, and assumptions.
2. Interpret a supplied result without confusing assumptions with observations.
3. Reproduce a simple calculation from provided synthetic data.
4. Identify at least two limitations or sources of uncertainty.
5. Explain whether the available evidence supports a stated conclusion.

4. Learning activities

- Review a short model specification.
- Work through a numerical example using synthetic data.
- Compare a model output with an expected result.
- Identify assumptions and possible failure conditions.
- Complete a short written assessment.

5. Assessment

Use five questions or exercises mapped to the five learning outcomes. Provide an answer key and scoring criteria before administering the assessment.

Use the four-level rubric from "learning-objective-matrix.md". Establish the passing threshold before testing and document the rationale.

6. Validation plan

Before calling the module effective:

- Review the instructions and answer key for correctness.
- Check that each assessment measures its intended outcome.
- Test the exercises with sample responses.
- Record ambiguous questions and revise them.
- If learners participate, record the sample size, procedure, and results before drawing conclusions.

7. Acceptance criteria

- [ ] All five outcomes have a corresponding assessment.
- [ ] Synthetic example data and expected answers are supplied.
- [ ] Scoring rules are documented.
- [ ] Assumptions and limitations are explicit.
- [ ] The module has been reviewed for clarity and correctness.
- [ ] Any effectiveness claims are supported by observed results.
